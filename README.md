## “ubuntu virtual server hosting” 究竟意味着什么

Ubuntu 虚拟服务器是一台运行 Ubuntu 的 KVM 虚拟化机器，可以通过 SSH 进行完全的 root 访问。你会获得一个专用的 IPv4、一部分 CPU 和 RAM、SSD 或 NVMe 磁盘，以及通过 apt 获取的完整 Ubuntu 软件包存档。没有任何限制：你可以安装 Nginx 或 Apache、Docker、数据库、游戏服务器、VPN 端点，任何你需要的东西。

这个定义为你提供了一个评估任何优惠方案的清单：

1. **虚拟化类型。** KVM 为你提供真正的内核、自定义内核以及良好的隔离性。OpenVZ/LXC 容器更便宜，但限制更多。这里涉及的主机要么销售 KVM，要么主打 KVM。
2. **Root 访问权限。** 如果套餐不包含完全的 root 权限，那它就是穿着 VPS 外衣的共享主机。
3. **Ubuntu 镜像选择。** 你需要确保有当前的 LTS 版本可用，并且以后可以重装。
4. **续费价格。** 重要的数字是你在第 13 个月支付的费用，而不是第 1 个月。这是各家供应商差异最大的地方。

## 该安装哪个 Ubuntu 版本

对于新的部署，安装 Ubuntu 24.04 LTS；它会获得直到 2029 年 4 月的安全更新。如果供应商脚本或控制面板特别要求，可以使用 22.04 LTS。避免使用更旧的版本。

| Ubuntu 版本 | 服务器支持状态 |
| --- | --- |
| 18.04 LTS | 自 2023 年 4 月起生命周期结束；请勿安装 |
| 20.04 LTS | 自 2025 年 4 月起生命周期结束；迁移所有剩余服务器 |
| 22.04 LTS | 安全更新至 2027 年 4 月；安全默认选择 |

两个实用建议。LTS 版本从 Canonical 获得五年的免费安全更新；临时版本只有九个月，所以它们属于台式机和测试机，不适合你可能会遗忘的服务器。由于在这些 VPS 套餐上你拥有完全的 root 权限，当 24.04 最终需要继任者时，`do-release-upgrade` 会处理原地的大版本升级；请先进行备份，并知道在小型服务器上，全新安装并迁移配置文件通常比原地升级更快。

## 在第一个小时内设置 Ubuntu VPS

整个过程只需不到 30 分钟：

1. 以 root 身份 SSH 登录（`ssh root@your-server-ip`）并运行 `apt update && apt upgrade -y`。
2. 创建一个非 root 的 sudo 用户，然后添加你的 SSH 公钥并禁用密码验证。
3. 启用防火墙：`ufw allow OpenSSH`，然后 `ufw enable`。
4. 如果服务器面向公共互联网，请安装 fail2ban（`apt install fail2ban`）。
5. 确认 unattended-upgrades 处于活动状态，以便自动应用安全补丁；Ubuntu 默认为安全库启用此功能。
6. 安装你的技术栈。Docker 只需一行命令：`curl -fsSL https://get.docker.com | sh`。LAMP：`tasksel install lamp-server`。Python 服务：`apt install python3-pip`，然后在 Nginx 后面配置 virtualenv 和 gunicorn。
7. 当天设置备份。在自助管理的预算套餐上这是你的工作；使用 cron 定时任务配合 rclone 推送到对象存储，成本极低且能挽救项目。

## 常见问题解答

**每年 10.99 美元的 VPS 真的可用吗，还是超售的垃圾？**
对于轻量级工作负载来说，它是可用的。1 GB 内存可以轻松运行带有 Nginx 的静态网站、小型数据库、WireGuard 隧道或几个机器人。它无法同时运行繁忙的数据库或六个容器。RackNerd 已经销售这些年度优惠多年，且相同价格的续费政策是人们持续购买的原因。

**促销价格在续费时会上涨吗？**
不会。只要你持有该套餐，促销费率就是你持续支付的费率。将其与主流主机进行对比，后者的 advertised 入门价格在续费时通常会上涨 40%–90%，在第二年和第三年，年度计算的差距会更加悬殊。

**以后可以更换 Ubuntu 版本吗？**
可以，有两种方式。从客户端区域重装不同的镜像（快速，但会清空磁盘），或者使用 `do-release-upgrade` 进行原地升级（保留所有内容，速度较慢，请先备份）。完全 root 权限意味着这两种选择都不会被阻止。

**年付促销还是月付套餐？**
如果服务器将存在 12 个月，选择年付促销；这是全部价格优势所在。月付仅适用于真正短期的项目。
